# sohamvg.github.io

Personal profile page. Live at **https://sohamvg.github.io**

Single static file — no build step, no dependencies.

- `index.html` — the whole site (markup + styles). Edit the `TODO`s.
- `.nojekyll` — tells GitHub Pages to serve the files as-is.

## Editing

Open `index.html` in a browser to preview locally, then:

```sh
git add -A && git commit -m "update profile" && git push
```

Live in ~30 seconds.
